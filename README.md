# Preparados

App de emergencias para la familia, para usar en el celular sin internet.

- Se abre en: https://TU-USUARIO.github.io/preparados/
- Los datos de cada persona (plan, fichas, inventario, lugares) quedan **solo en su celular**. Este repositorio tiene únicamente la app, sin datos personales.
- Mapa de Azul: © colaboradores de OpenStreetMap (ODbL). Límites provinciales: IGN, vía argentina-map-react (MIT). Generador de QR: qrcode-generator (MIT).

Para publicar una versión nueva: reemplaza `index.html`, sube el número en `sw.js` (`preparados-v2`, `v3`…) y haz Commit + Push en GitHub Desktop.
